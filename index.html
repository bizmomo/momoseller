내용을 여기서 바로 고칠 수 있어요.

1. 쿠팡 주문 엑셀

쿠팡윙에서 받은 주문/발주 엑셀 파일 (없으면 비워두세요)

2. 스마트스토어 주문 엑셀

스마트스토어 판매자센터에서 받은 주문 엑셀 파일 (없으면 비워두세요)

3. 쿠팡 수수료율 설정

카테고리를 고르면 판매수수료가 자동으로 채워져요. 목록에 없는 카테고리면 "직접 입력"으로 두고 쿠팡윙 → 정산관리에서 확인한 요율을 직접 넣어주세요. 배송비 수수료는 여기 입력한 값에 VAT 10%가 자동으로 더해져요. 스마트스토어는 실제 수수료 데이터를 그대로 가져오기 때문에 별도 입력이 필요 없어요.
실배송비(택배비) 열은 마켓 데이터에 없는 정보라 빈 칸으로 나가요 — 다운로드한 파일에서 직접 채워주시면 순수익이 자동으로 계산돼요.
스마트스토어 수수료 열은 원본 파일의 "네이버페이 주문관리 수수료"·"매출연동 수수료" 값을 그대로 사용해요. 업로드한 파일은 이 화면(브라우저) 안에서만 처리되고 어디로도 전송되지 않아요.
