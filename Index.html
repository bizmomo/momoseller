상품 등록 문구 생성기

대충 설명만 적으면 상품명, 해시태그, 소개글을 뽑아드려요. 한 개씩 또는 여러 개 한꺼번에 가능해요.

개별 입력
일괄 입력 (여러 개)
일괄 입력 시 여기 적은 브랜드명이 모든 줄에 공통 적용돼요. 상품마다 브랜드가 다르면 각 줄 설명 안에 브랜드명을 직접 적어주세요.
사용법
  1. 아래 칸에 상품 설명을 한 줄에 하나씩 적기 (최대 20개)
  2. "생성하기" 누르면 순서대로 처리돼요 (개수가 많으면 시간이 좀 걸려요)
  3. 결과가 나오면 "엑셀용으로 전체 복사"를 눌러서 엑셀에 그대로 붙여넣기
최대 20줄까지 한 번에 처리돼요. 처리에 시간이 좀 걸릴 수 있어요.

상품명

스마트스토어 검색태그 (10개)

쿠팡 검색어 (20개)

상품소개글

결과 (0개)

결과는 초안이에요. 실제 등록 전에 정확한 스펙(치수, 소재, 원산지 등)은 꼭 확인하고 붙여넣어 주세요. "엑셀용으로 전체 복사"를 누르면 엑셀에 붙여넣었을 때 상품명 / 해시태그 / 소개글이 각각 열로 나뉘어 들어가요.
